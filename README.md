# Verificación de modelos de regresión lineal
## Descripción
En este proyecto se realizo un análisis de relación entre el desempeño escolar de alumnos en escuelas y el porcentajes de estos estudiante que reciben comidas gratuitas, para ello se emplearon modelos de regresión lineal y pruebas estadísticas para evaluar supuestos del modelo y comparar resultados
## Objetivo
Evaluar y ajustar modelos de regresión lineal usando pruebas estadísticas y corroborando supuestos de linealidad, homocedasticidad y normalidad
## Librerías aplicadas
- ggplot2
- lmtest
- car
- multcomp
## Procedimiento 
1. Ajuste del modelo de regresión lineal
2. Interpretacion de gráficas y estadísticas del modelo
3. Ajuste de un segundo modelo de regresión
4. Comparación de los modelos usando ajustes R*2 y ANOVA
5. Interpretación de pruebas de hipótesis acerca de la relación de las variables
## Conclusiones
El modelo ajustado con la variable que se transformo tuvo un coeficiente de determinación R*2 de 0.8286 y al confirmar las pruebas de hipotesis concluimos que a mayor porcentaje de alumnos que reciben comidas gratis, su promedio es mejor
